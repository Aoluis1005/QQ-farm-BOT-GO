# ⚠️ 测试版 QQ 农场 Bot（Go）

> **本版本为测试版，可能存在 Bug**——遇到问题请 [提 Issue](https://github.com/Aoluis1005/QQ-farm-BOT-GO/issues)。
>
> ✅ 支持最新**七夕活动「鹊桥寄情」**：灵露喷洒、筑建鹊桥、档位奖励已可用
> ⚠️ **送香囊功能未完成**（协议已搭好，缺 cmd 参数，待真机抓包补全）

基于 QQ 农场微信小游戏协议的自动化挂机 Bot（Go 实现）。

## 功能

- 农场自动化：种植 / 收获 / 卖果实 / 施肥 / 除草除虫 / 一键务农
- 好友自动化：巡查偷菜 / 帮忙务农 / 放虫放草 / 护主犬
- 活动自动化：每日任务 / 活跃奖励 / 图鉴点券 / 商城免费礼 / 每日分享
- 七夕「鹊桥寄情」：灵露喷洒（自动触发鹊羽效果）+ 筑建鹊桥（档位奖励）
- 神秘商人自动购买、自动重连、自动卖果实
- Web 管理面板（首页数据 / 好友巡查 / 商城 / 活动 / 分析 / 每日任务）

## 声明

- 本仓库**不含**任何逆向工具、解包产物或敏感凭据（openid / 加密材料），请勿提交此类文件
- 仅用于学习与个人自动化研究，请遵守游戏用户协议
- 测试版随时可能有 Bug，请以 Issue 反馈，我会尽快修复

## 快速开始

```bash
# 编译（Go 1.20+）
CGO_ENABLED=0 go build -o go-farm-bot .

# 运行（默认监听 3009 端口，首次访问 /api/admin/setup 设置管理密码）
./go-farm-bot
```

详细配置见管理面板：浏览器打开 `http://<服务器>:3009`
